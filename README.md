# Smallnews: Live News Update

## Installation

### Pre-requisites:
1. Create an `.env ` file.
2. Add this Key  `NEWS_API_KEY` and use newsapi.org 's API key. 
3. Rate Limit: 1000 Reqs in free version. Please check the daily api calls limit from their website.

## Flutter packages:
Run `flutter pub get` to install all the packages
